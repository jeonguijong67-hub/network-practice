######## TCP TTL sweep  (ttl_probe.py, no admin rights needed)
# For TTL = 1..30, open a TCP connection to port 443 with IP_TTL set on the socket.
# A SYN that expires in transit never gets a SYN-ACK, so connect() times out; the
# smallest TTL that connects is the number of router hops to the target, and the
# connect() time at that TTL is one round trip. TCP/443 passes the campus firewall
# where ICMP does not. It cannot name intermediate routers (the time-exceeded goes
# to the kernel, not to the socket), only count them.
#
#   target            address          hops   RTT at that TTL   5 more connects (min / median)
#   www.korea.ac.kr   163.152.6.10        8        32.9 ms            6.6 /   7.7 ms
#   www.snu.ac.kr     147.46.10.129      15        11.3 ms            9.9 /  20.1 ms
#   www.stanford.edu  15.197.167.90      16         4.1 ms            3.5 /  15.9 ms  (3.33.186.135)
#   stanford.edu      171.67.215.200     19       141.2 ms          142.0 / 147.1 ms
#   1.1.1.1           1.1.1.1            14         3.3 ms            4.6 /   5.4 ms
#
# Single connects are noisy (korea.ac.kr 32.9 vs 6.6 min); read the min column.
